# Jogo Amigo Secreto

Aplicação web para sorteio de amigo secreto, desenvolvida como parte da minha jornada de aprendizado em desenvolvimento Front-End.

---

## Sobre o projeto

O **Jogo Amigo Secreto** permite que o usuário adicione nomes de participantes e realize um sorteio aleatório, revelando quem é o amigo secreto de cada rodada. O projeto foi criado com foco na prática de lógica de programação com JavaScript puro e manipulação do DOM.

---

## O que esse projeto faz

* Permite adicionar nomes à lista de participantes
* Exibe os nomes adicionados em tempo real na tela
* Realiza o sorteio aleatório de um nome da lista
* Exibe o resultado do sorteio para o usuário
* Valida entradas para evitar nomes em branco ou lista vazia

## Como rodar o projeto

**1. Clone o repositório:**

```
git clone https://github.com/ericfariasds/Jogo-Amigo-Secreto.git
cd Jogo-Amigo-Secreto/desafio-amigo-secreto_pt-main
```

**2. Abra o arquivo no navegador:**

```
# Basta abrir o arquivo index.html diretamente no navegador
xdg-open index.html        # Linux
start index.html           # Windows
open index.html            # macOS
```

Não é necessário instalar dependências — o projeto roda diretamente no navegador.

---

## Como usar

1. Digite o nome de um participante no campo de texto
2. Clique em **"Adicionar"** para incluir o nome na lista
3. Repita o processo para todos os participantes
4. Clique em **"Sortear amigo"** para realizar o sorteio
5. O nome sorteado será exibido na tela
